# Car Dealerships Application

A full-stack car dealership application developed as part of the IBM Full Stack Application Development Capstone.

## Project Overview
The application allows users to browse car dealerships, view dealership details, filter dealerships by state, register and log in, and submit customer reviews.

## Features
- User registration, login, and logout
- Browse dealerships and filter by state
- View dealership details and customer reviews
- Retrieve car makes and models
- Submit dealership reviews
- Analyze review sentiment

## Technology Stack
- Frontend: React, JavaScript, HTML, CSS, Bootstrap
- Backend: Python, Django, Node.js
- Database: MongoDB
- CI/CD: GitHub Actions
